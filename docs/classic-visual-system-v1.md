# ALLWE 经典版 · 全站视觉系统 V1

适用范围：`http://<本机私有IPv4>:5176/` 对应的经典版，不覆盖正式版 5173。

## 目标与原则

- 统一全站视觉而不统一所有页面的业务结构：创作页突出素材与主操作，任务页突出成果和下一步，管理页突出数据、表格和可查验性。
- 先减少容器嵌套、建立正确的视觉层级，再考虑阴影、色彩等装饰。
- 预览直接点击视频；下载只提供一次主入口；历史结果逐级收敛。
- 保留已有状态语义：`已查看 ≠ 已审核通过`、`自动送剪已开启 ≠ 已有真实剪辑任务`。
- 视觉优化不改变授权、生成参数、API、费用、生成提示词及历史数据。

## 实现

共享覆盖层：`frontend/src/visualSystem.css`，在入口的 `styles.css` 后加载。
原则上只修改可视组件和 CSS，不改变生成、校验和剪辑调用。

### 页面专属原则

| 页面 | 信息重点 | 视觉策略 |
| --- | --- | --- |
| 图片中心 | 图像、生成任务、批量操作 | 统一图片面板和操作条，不牺牲可视素材区 |
| 视频制作 | 上传素材、分镜、生成设置 | 一块大工作区，减少小卡片边框与色条 |
| 任务中心 | 哪个任务需要看或处理 | 紧凑、可扫描的行式列表；未看只提示新成片 |
| 任务详情 | 当前阶段或最新成片 | 状态自适应，成片大舞台，历史用行式折叠 |
| 内容库 | 内容对象、搜索筛选、复制编辑 | 统一网格卡片和检索工具栏，弱化装饰 |
| 管理中心 | 运行状态、账号与审计 | 稳定的表格密度和统一间距 |
| 设置 | 字段、说明、开关与权限 | 简洁的表单分组，统一输入框与操作按钮 |

## 验收要求

- UI 源码及 CSS 构建通过、Lint 通过、全量前端测试通过。
- 桌面和窄屏内容不溢出；导航和主操作不消失。
- 真实媒体缩略图依然打开原来的预览弹窗，下载地址不变。
- 测试覆盖全站样式入口、全部主要页面选择器、任务详情的结果舞台、响应式与减少动画偏好。
- 发布后需验证当前经典版 JS/CSS 指纹已加载，API 和 Runner 健康，历史任务和计费数量不变。
- 浏览器实际视觉和人工操作验收分别记录，不将静态测试等同于用户现场验证。

## 后续维护

`visualSystem.css` 是跨页面的设计规则层。业务组件继续在其对应文件维护局部布局；不要增加与共享规范相矛盾的全局覆盖。新增页面首先复用现有排版、表单、按钮和状态规范，而不是新建一套视觉语言。
